HTML CSS and JS project on a keyboard web tester where u test the keys of your keyboard and it shows if the key press is detected. It highlights the key thats pressed on the virtual keyboard and marks it. Shows previous key presses and has a bar progress stating how many keys that havent been tested yet. It also has a restart button to start again 

To run it, click this link: https://arnav-on-top.github.io/TapTest/ or click the link displayed in the deployments. 

Built as a project for Hack Club's GrandMa YSWS [You Ship We Ship] Program under the constrains of:

1. No server or database: all state lives in the URL or the browser.

2. No third-party libraries or engines.

3. No if statements, switches or ternaries.
